# Map, location and region admission

**Status:** accepted design. Published schema/config and comment scaffolds do not implement these contracts. Runtime enforcement remains pending the owning implementation tasks and their tests.

Pattern is aggregate commands with consumer-owned admission interfaces. Root engineering rulings on2026-10-16 complete geometry/input choices while retaining D6 and D7 ownership. This is one shared Document location predicate, not an alternate Spatial interpretation.

MapCreate for pointcrawl permits null regionId, cols and rows. Supplied dimensions are1..1000 and persist literally; no geometry is automatically created. A regionless map admits only admin/configured-owner writes. Hexgrid requires a current live region and both dimensions1..1000. assetPath is nullable and at most2048 characters. A supplied path is either a root-relative single-slash path or an HTTPS URL. Reject userinfo, javascript schemes, backslashes and dotdot path segments. The API never fetches that value.

Hex terrain/elevation/climate are nullable trimmed author text, at most64 characters, with no invented lookup enum. HexEditInput uses omitted-preserve/null-clear for those fields and submapId; its note remains required. HexEdge aSide is nullable opaque author text up to64 characters, null/omission clears under full replacement. Pointcrawl edge kind is trimmed nonempty text up to64; label is nullable up to200. Hex edgeType retains the six stored allowed literals. Point coordinates accept every finite float64 representable by PostgreSQL, with no additional arbitrary magnitude bound.

A submap must be an existing distinct map. Actor stewardship applies to both maps. One Map-owned containment lock guards all submap mutations and cycle checks. SPA04 `ContainmentWriter.LockContainment(ctx)` takes the transaction advisory lock for hashtextextended('chronicler:map-containment',0). The actual signed64 hash value is the lock key; SQL owns hashing. Every map/hex/node submap mutation takes this lock before Document or Map row locks, then reads the current whole directed containment graph through set SQL and rejects a new cycle. Source/target UUIDs are locked in ascending order after that admission. No cached graph or per-process mutex admits a write. SPA06 invokes this provider in the same business transaction, without a nested runner. All other operations that could create/remove containment edges use the same provider.

Document `LocationAdmissionReader.AdmitLocationLink(ctx, actor, documentID, targetRegionID)` locks the Document before the Map row for location links and returns the exact existing linked-region set plus the admitted target. W01 binds it to the same transaction. DOC04 owns the query and canonical location policy; DOC06 uses the same admission for Document location mutations. The document must be a nondeleted Locations entry. If unlinked, target-region stewardship admits an assigned archon. If already linked, its owning region must equal the target; D7's declared admin/configured-owner bypass remains explicit and audited. An author alone is insufficient, while the assigned archon need not be the author. Location region derives from existing owning links, not a new Document.region column. Hex and pointcrawl link commands call this same provider before locking their target Map. Non-location ordinary link policy remains Document-owned. Tests that use010 apply an explicit isolated categoryLocations overlay; its normal Lore fixture is not sufficient.

Hex relation is trimmed nonempty author text up to64 because D6 supports terrain as well as location. location retains D6 strict one-to-one through both unique indexes; other relation values are typed claims. Duplicate exact link with a new command key is CONFLICT. Unlink of an absent exact identity is a no-op plus a receipt, with no invented history. Pointcrawl location/subject vocabulary and its node-scoped identity remain dm-table-independent as already frozen.

RegionInput is full replacement, but updateRegion requires kind equal to the stored kind. transitionRegion owns lifecycle changes. charterDeadline may be null or supplied for any existing kind; no new deadline/kind invariant is invented. Delete soft-tombstones only when no active referencing map, Character or quest-region relationship exists; otherwise CONFLICT without moving foreign data. Inactive references and history remain. Repeated deletion and restore of active are no-ops. Restore checks existing constraints without inventing name uniqueness.

Archon assignment requires admin or configured owner, and a current active archon target, otherwise INVALID. New-key duplicate assign returns original immutable assignment plus a new receipt, zero history. Revoke absent is a no-op plus receipt. Same-key replay preserves original timestamps. Character ownership exceptions remain unchanged.

P04 owns schema/index/history additions, SPA04 owns containment/history/assignment persistence, DOC04 owns location admission, SPA06 and DOC06 own validation/application. S04 must add exact cases for null/supplied pointcrawl dimensions, regionless authority, path rejection, text64/65, finite extremes, cycle A->B->C->A under concurrency, categoryLore denial versus Locations overlay, both D6 uniqueness directions, kind-edit rejection, assignment duplicate/no-op, and active-reference deletion. Existing mounted-spatial-write-cases unresolved markers remain open until those precise assertions are amended. This contract alone is not a passing case receipt.

A required Hex/Region note may be the empty string. Persist it literally on an actual change. An unchanged Hex patch is no-op plus a new receipt with no history or timestamp change. One multi-field patch produces one complete before/after fact in hex_changes. Undirected pointcrawl endpoint order is public UUID ascending; directed order is the exact input. Existing hex_edges ordering is its existing internal bigint constraint. aSide is relative to that canonical stored A regardless of input endpoint order; the API returns the actual stored A/B public identities and never silently inverts the authored aSide.
