# One GraphQL transport, codecs and execution boundary

**Status:** accepted design. Published schema/config and comment scaffolds do not implement these contracts. Runtime enforcement remains pending the owning implementation tasks and their tests.

Pattern: adapter/anti-corruption layer, dependency injection and specification. Domain DTOs remain transport independent. G05 owns the transport-only package `internal/platform/graphql/scalars` and its exclusive codec tests; root-controlled gqlgen generation depends on that actual Phase3 foundational implementation, not a Phase2 function stub. Phase2 publishes comment scaffolds/config only, as the approved plan states.

## Exact model bindings and codecs

Use module path `github.com/piyushsatti/chronicler/apps/api/internal/platform/graphql/scalars`. ID binds scalars.ID (alias string), Date binds scalars.Date (alias product.Date), Time binds scalars.Time (alias product.Time), DateTime binds scalars.DateTime (alias time.Time), JSON binds scalars.JSON (alias json.RawMessage). Default Int remains graphql.Int. Generated transport enums remain generated; G03 explicitly converts them into domain enums/patch values.

G05 package functions are MarshalID(string), MarshalDate(product.Date), MarshalTime(product.Time), MarshalDateTime(time.Time), MarshalJSON(json.RawMessage), and matching Unmarshal functions `(value any)(concreteType,error)`. Marshal functions return `gql.ContextMarshaler`; they can report an opaque serialization failure rather than returning an empty invalid scalar. The qualifier gql denotes github.com/99designs/gqlgen/graphql, distinct from the local transport package. No domain type implements gqlgen interfaces or imports graph.

ID input must be a canonical UUID string, accepting uppercase and normalizing lowercase; integer/bigint/empty/malformed values INVALID. Output comes from actual UUID mapping; empty or malformed required identities are mapper invariant failures before serialization. Date is strict YYYY-MM-DD round-trip. Time is canonical HH:MM:SS, accepts HH:MM or HH:MM:00 and end-of-day24:00:00; nonzero seconds or24 with nonzero minutes reject. Availability additionally rejects24 as a start. DateTime requires RFC3339 with zone, normalizes UTC, and accepts precision representable by PostgreSQL microseconds; sub-microsecond nonzero precision rejects INVALID instead of silently rounding a concurrency token. Clock-derived write timestamps normalize UTC/microseconds once through the shared product clock helper; repositories return actual persisted timestamps.

JSON input preserves objects/arrays/primitives and exact json.Number values, bounded256KiB/depth16; no URL/schema fetch. The pinned gqlgen POST decoder uses UseNumber (`graphql/handler/transport/http_get.go` jsonDecode); do not replace it with float64-decoding. Domain fields impose their own object schemas afterward. Output is actual valid raw JSON, not a string containing JSON. Required nil/malformed persisted JSON is an owning mapper invariant failure; no invented empty object except the explicitly documented legacy absent-frontmatter meaning. Serialization failures produce opaque INTERNAL and staged data:null; never expose invalid partial nonnull JSON/ID output.

For patch input MemberSettingsPatch, DocumentEditInput, QuestEditInput and UpdateCharacterProfileV2Input, mark every nullable SDL field omittable in gqlgen.yml. Required expectedRevision/expectedUpdatedAt fields are not omittable. G03 maps IsSet=false to product.Optional.Set=false, explicit null to Set=true/Value=nil, and value to Set=true/non-nil converted domain value. Other full replacement/create input types map omitted nullable and explicit null to their documented default/clear semantics, without changing domain inputs to gqlgen.Omittable.

Every nested output field with arguments is resolver-backed, plus identity relationships Document.author/summaryDerived, Quest.dm/arc/briefDocument/discordDelivery, GameCalendar.currentGameDate, and the other typed relationships in the final resolver inventory. Generated hidden extraFields carry only internal parent UUIDs needed by paged fields (e.g. MemberActivityStatsType.MemberID with json:"-"); they are not selectable SDL or user-supplied authority. G03 owns the exact base DTO→generated model mapping; nested owners invoke typed loaders, never direct SQL.

## Pure validation before live authority

T01 stages body size/JSON and document validation before DB. GraphQL syntax/type/argument shape/scalar coercion/depth/cost rejection has no authority/business SQL or effects. Unknown/duplicate envelope keys/malformed JSON produce generic transport400 without echoing request bodies; body>256KiB413. Scalar prevalidation invokes the same G05 codec functions on resolved literal/variable values, not a second Date/UUID interpretation. Domain constraints/state admission follow live authority and remain expected values; no command effect precedes them.

Only after pure validation/costing does T01 invoke P07's ResolveGraphAuthority(ctx,claims,resolve) adapter (**implemented** as the GraphQL `liveAuthority` operation interceptor). Anonymous permits nil authority/public operations; authenticated identity resolves current Member state once, errors use GraphQL extensions.code, no REST Problem response. T01 creates G04 RequestState, creates G02 typed loaders and installs them before execution. Failures building that request state (or its loaders) log the cause and answer one GraphQL `errors[]` entry through the same presenter—never silent continue and never `application/problem+json` on this route. Resolver panics are caught by `SetRecoverFunc`: slog with stack, returned as `apierr.Internal` through the presenter. W05 supplies the trusted live resolver and service providers; it does not wrap GraphQL in REST LiveMiddleware. Retained HTTP protocols keep their existing live middleware/Problem semantics. Invalid/missing/inactive identity cannot fall back to Claims role bits.

T01 NewHandler takes the nonnil graph Resolver, validated Limits and live AuthorityResolver and returns `(http.Handler,error)`; missing service/config rejects construction rather than serving PlaceholderHandler. G01 NewResolver validates all seven domain ProductQueries/ProductCommands, replacing the legacy service fields. FixedComplexityLimit/depth conflation are removed; T02's one AST specification owns actual depth, weighted cost, alias and cardinality validation. Runtime examples/tests use that same specification and frozen cardinalities. Staged response limit2MiB never sends half a JSON result; committed mutation receipts survive any later encoding/refresh failure, as explicitly documented.

## Concrete codec/boundary acceptance

G05/S03: UUID uppercase→same lowercase; 1/empty/foreign numeric ID INVALID with zero authority SQL. Date2026-10-14 stays that date rather than midnight DateTime;2026-2-14/2026-02-30 INVALID. DateTime2026-10-14T13:00:00+01:00→2026-10-14T12:00:00Z; .123456 accepted, .1234567 rejected; no zone rejected. Time09:00→09:00:00,24:00→24:00:00,09:00:01 rejected. JSON integer9007199254740993 remains exactly that integer in persisted/readback JSON; object-key order/whitespace canonicalization does not lose it. Depth16 accepted/depth17 INVALID, request payload bounds still apply.

T01/P07/S03: syntactically invalid document, invalid scalar, depth13, cost100001, alias21 and oversized body execute zero live authority/business queries. Valid authenticated operation performs live lookup then real execution. Missing Member/inactive Member returns GraphQL codeFORBIDDEN and no old authority; failed lookup INTERNAL with no fallback. Public anonymous query executes without fabricated authenticated identity. Retained HTTP errors remain Problem JSON. A nil resolver/one missing domain service causes constructor error. Inject malformed mandatory UUID/JSON mapper output: opaque INTERNAL/data:null, no fake empty identity and no partial nonnull response. These are future owned tests, not Phase1 runtime receipts.

Pinned variable String conversion uses the actual gqlgen.UnmarshalString after POST UseNumber: numeric json.Number lexemes become their string bytes (7→"7"), while object/array values reject INVALID before authority. Literal GraphQL String document validation remains the pinned parser's rule. Do not substitute a stricter helper and claim the mounted handler rejects accepted numeric variables. Boolean variables still pass gqlparser's Boolean shape check before gqlgen conversion. Custom UUID/Date/JSON codecs retain their explicitly declared stricter rules.

Every amount-derived telemetry value preserves stored DOUBLE PRECISION: ActivityEvent.amount and sums of voice/message/reaction amounts are Float, including weekly/channel aggregates. Count metrics remain Int. GraphQL serialization of nonfinite telemetry fails opaque INTERNAL/data:null; no rounding or event-row-count substitution. Current whole-minute bot producers do not reinterpret fractional historical facts.
