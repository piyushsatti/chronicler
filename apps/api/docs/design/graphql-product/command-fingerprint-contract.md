# One command fingerprint

**Status:** accepted design. Published schema/config and comment scaffolds do not implement these contracts. Runtime enforcement remains pending the owning implementation tasks and their tests.

Pattern: idempotent command receipt. P01 owns product.Fingerprint(normalizedSpec any) (string,error), a pure shared function. Domain commands normalize boundary UUID/date/time codecs, defaults and set/replacement semantics first, without consulting mutable database state. They exclude meta, actor, operation scope, server-generated IDs and clocks from its argument. Actor/operation/key form the separate receipt uniqueness scope. D9 stored spellings are looked up after the receipt fingerprint; current database state must never change a replay's hash.

Canonical bytes are: encoding/json.Marshal(normalizedSpec); decode the complete tree with json.Decoder.UseNumber, rejecting trailing data; encoding/json.Marshal that tree. This sorts object keys recursively with Go's default HTML escaping. It preserves array order, string bytes and exact json.Number lexemes; number1 and1.0 are intentionally distinct. SHA-256 of those bytes is lowercase hex. No domain invents its own JSON canonicalization. Serialization errors fail before business writes.

product.Optional[T] carries exported Set and Value and must enter normalized patch input unchanged: omitted {Set:false,Value:null}, explicit clear {Set:true,Value:null}, supplied {Set:true,Value:value} are distinct. Full replacements collapse omitted/null only where the owning contract says identical. UUID canonicalization occurs before hash; upper/lower UUID inputs normalized to one value. Arrays remain ordered unless an explicit owning set rule sorts them. Fingerprint equality does not grant replay disclosure: current authority is checked first; mismatched normalized input with an existing key is CONFLICT, with no writes. All committed results/history/event/job IDs remain captured from the original transaction.

P01 tests include nested key order equality, HTML escaping, UTF8 strings, json.Number1 versus1.0,9007199254740993 exactness, array reversal inequality, patch omission/null/value distinction, equivalent normalized UUIDs, invalid serialization, trailing-data rejection and DB-independent D9 spelling. P03 tests actor/operation scoping, concurrent claim and complete-receipt atomicity; S04's explicit per-root metadata cases bind the same primitive and actual owning command effects/replay/rollback. No test may hash raw transport envelopes or silently include server time/IDs.
