Pattern: dependency DAG with one coupled Go package integration unit. Source-complete files are not compile/runtime PASS. This is a Phase3 handoff after Gate2, with S01's deterministic complete SDL discovery completed earlier in Phase2 after Gate1. No generator is run during Phase1.

ROOT-REMOVE-ROOTS performs the exclusive pre-generation transition after domain provider source is complete and before G01 replaces the old Services fields. Its manifest freezes the actual four source paths and hashes: roots.resolvers.go, document.resolvers.go, quest.resolvers.go and mappers.go. Root journals the exact source path/hash, archive destination/hash and transition state. It first copies exact bytes to its named run archive and verifies SHA256, then removes those obsolete handwritten files from the active graph package. A retry may resume only when absent source has a matching archived original and staged journal, or when present source still equals the frozen original. Unexpected bytes, including a newly implemented mapper/resolver, refuse staging unchanged; never remove handed-off source. No root-level test or app compile is called PASS while source is incomplete. The graph package build is checked when this complete source unit exists. A generator result or skeleton compilation is not an implemented resolver acceptance result. There is no stub service or temporary handwritten implementation.

Root never runs generation concurrently with these owners. Legacy graph tests keep their existing exclusive LEGACY-2/3 owners and migrate real assertions after the new graph surface exists. Source compilation/unit tests involving them are pending until those owners finish. A failed or unavailable check remains failed/pending, never a PASS for an individual file.

The final coupled integration unit includes G01/G02/G03/G04, seven domain07 resolver owners, six NEST owners and LEGACY-2/3. Root runs actual validated generation/drift again after handwritten bodies are complete, rejects overwritten bodies/unlisted emissions, and executes native `go test ./internal/graph ./internal/test` plus the required whole API tests. G01's source prerequisites, generation success, graph package compile and complete mounted/runtime acceptance are distinct retained receipts. This order changes no owning API or file allocation and adds no redundant source owner. Sequential root staging of the four old files ends before each handwritten owner starts.
