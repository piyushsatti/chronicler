**Status:** accepted design. Published schema/config and comment scaffolds do not implement these contracts. Runtime enforcement remains pending the owning implementation tasks and their tests.

The SDL is the accepted wire authority; no field is optional to implement merely because its current resolver is a placeholder. Every persisted field maps its named column or computed derivation listed below. Any mapper cannot meet that rule must change persistence or nullable contract by reopening the accepted contract and dependent review.
