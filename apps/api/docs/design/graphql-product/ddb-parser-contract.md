## Sync command preflight, replay and persistence

`character.DdbPreflightReader.ReadDdbPreflight(ctx, actor, characterID)` is CHA04's pool-backed pure reader. Its result carries immutable owner, current version/updatedAt, status and current nullable URL. CHA06 resolves fresh live authority through its pool `LiveAuthority`, checks literal owner and an existing, non-tombstoned Character (retired/dead historical rows may sync; active actor required), canonicalizes the supplied URL, and computes the actor/operation/input fingerprint before `idempotency.CompletedReceiptReader.LookupCompleted`. That P03 pool-backed method returns `(json.RawMessage, bool, error)` and never creates/claims/completes receipts. A completed matching receipt returns without HTTP only after the fresh owner/authority check. Different input for the same actor-operation-key returns CONFLICT without HTTP. Missing receipt proceeds; no database connection is retained during the call.

CHA06 calls C08's client once outside the unit of work. Its command constructor explicitly receives DDB, Preflight, ReplayReader and LiveAuthority; no unused constructor dependency is permitted. Then the normal command runner begins one transaction, resolves live authority again, locks Character and verifies the captured version/updatedAt/owner. Changed owner/status/version returns the expected forbidden/conflict outcome, discards the fetched payload and commits no attempt/link/mirror/receipt. Otherwise claim the replay key again in this transaction. A concurrent caller may have fetched independently; if the first committed already, the second returns its matching receipt without another persisted attempt. This is at-most-one admitted attempt/receipt per key, not physically exactly-one external request under concurrent cold misses.

Admitted success writes the selected canonical URL, exact parsed mirror/proficiencies, successful attempt/provenance, actual updatedAt and completed receipt atomically. Admitted provider/shape failure records the attempted selected URL and safe failure/provenance plus failed attempt and completed `succeeded:false` receipt; the desired character URL is stored, while the last-good mirror and its own provenance remain unchanged. The failed attempt is a real effect, not successful enrichment. Attempt-write/receipt failure returns opaque INTERNAL and rolls back all selected URL/attempt/mirror/time changes; it cannot acknowledge a durable failed attempt that did not commit. No inbox event/job or approval state change is generated. Approval has no DDB prerequisite.

C08 `NewDdbClient(client *http.Client, clock product.Clock)` rejects nil dependencies, clones the client before installing its redirect/deadline rules and never mutates the caller's client. Production W02 calls C08 `NewProductionDdbHTTPClient() (*http.Client,error)` and supplies that safe transport: exact admitted HTTPS provider authority, DNS results excluding loopback/private/link-local/metadata, and dialing a validated resolved address with the original TLS server name. User URL is only a public character-sheet numeric identifier; remote origin/path is rebuilt server-side, never fetched verbatim. Redirects are at most3 and remain within the same admitted provider authority; timeout10 seconds includes resolution/redirect/body/parser and body remains2MiB maximum. Transport injection belongs only to trusted constructor wiring; local tests use a per-instance fake RoundTripper recording the admitted origin and returning dated captured bytes, never a production host override, mutable global hook or live-provider success claim.

Exact mounted cases: successful dated capture persists one attempt and the vetted projection; matching key replay has zero additional fake-HTTP calls; wrong owner/admin/platform owner is forbidden with zero calls even when a receipt exists; stale preflight after the fake HTTP barrier commits zero attempts/URL/mirror/receipts; two cold-miss identical keys may call twice but admit one attempt/receipt; injected attempt/receipt write failure leaves every preexisting value unchanged. Fetch timeout, shape drift and optional-link changes preserve prior mirror while recording exact failure/current selected URL. A new key makes an explicit new attempt. These assertions belong to S04's mounted mutation test, CHA06's command companion and C08's local transport/parser tests with unique per-file ownership.
