# Goals

Member-visible journeys as verb chains. Verbs: [verbs.md](/docs/semantics/verbs.md).

| ID  | Goal                                                    | Verb chain and observable completion                                                                                                                                                                                                                                          |
| --- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G01 | Understand the community/world                          | V01 public home/directory → detail → linked record; reader can identify actors/places/history; missing or placeholder surfaces are gaps                                                                                                                                       |
| G02 | Secure a place in an adventure                          | V01 quest discovery → V02/V03 eligible character → V05 join → reload/fresh read; own participation and capacity agree, or waitlist state is explicit                                                                                                                          |
| G03 | Relinquish a place fairly                               | G02 participation → V06 withdraw → reload/fresh read; withdrawn state, capacity and any FIFO promotion agree; repeat cannot double-decrement                                                                                                                                  |
| G04 | Preserve an adventure's history                         | V04 organize → V05 recruit → external play → V07 transition/close quest (lifecycle) → V17 attest participation where needed → V08 summary → V10 publish → V01 later retrieval; pilot scope may not prove the full chain                                                       |
| G05 | Publish to the intended readers                         | V09 draft → V10 publish → V11 audience → separate reader identities execute V01; allowed content persists and forbidden content/action is denied                                                                                                                              |
| G06 | Maintain a shared world                                 | V13 changes authorized place/time → linked N07 records → V01 discovery; unavailable browser map/calendar routes keep this journey partial                                                                                                                                     |
| G07 | Operate a reliable community record                     | V20 configure authority → V28 ensure scheduled slots / V25 advance Discord desired state → V23 execute work → V26 apply projection → V29 deliver sensor events → V32 observe failure/recovery; queue acceptance, external side effect, and projection stay separately visible |
| G08 | Express earned identity/preferences                     | V01 discover catalog (N17) → V19 grant/equip unlock → V14 configure preferences → observe persistent profile/preferences                                                                                                                                                      |
| G09 | End a character's active play while keeping its history | V01 inspect character and live commitments → V06 withdraw where necessary → V24 confirm retirement → reload/fresh read; retired state persists; V05 refuses new signup                                                                                                        |

Initial runtime scenarios: anonymous discovery, open signup, full/waitlist/withdrawal, document draft/publication, contrasting audience/ownership. Passing one does not validate every role, lifecycle edge, or production integration.
