# Requirements — Operations

System: [operations](/docs/systems/operations.md)

## Requirements

| #   | Requirement                                                                                                                                                                                        | Current evidence boundary                                                                                                                                                                                                                                                                               |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | Handle credentials through the owning secret/identity boundary, with owner input only for externally issued values. Production release credentials are scoped to an admitted Actions mutating job. | [Secrets guidance](/deploy/docs/secrets-overview.md) and [actions-releases R6](/docs/interfaces/actions-releases.md) state the boundary. The legacy vault/push helpers are absent; current production access and rotation enforcement require verification.                                             |
| R2  | Keep nightly and pre-deployment pull backups durably on the owner's workstation, off-provider and off-droplet, and admit current restore-point evidence before migration.                          | [D10](/docs/decisions/D10-Backup-Location-And-Cadence.md) retains policy. [Backup guidance](/deploy/docs/supabase-backups.md) records missing helpers/workflow integration and requires isolated recovery proof. Historical non-empty dumps and restore transcripts do not establish current operation. |
| R3  | Make operator-facing failures, missed runs, backup failures and terminal work visible through an alert path outside the bot process's failure domain.                                              | [D23](/docs/decisions/D23-One-Work-Table-Out-Of-Band-Alerts.md) retains the out-of-band boundary. End-to-end current alert delivery and coverage remain unverified; durable work alone does not establish alerting.                                                                                     |
| R4  | Admit, execute, verify and recover production releases through one Actions run, retaining non-secret evidence.                                                                                     | [Actions release contract R1–R8](/docs/interfaces/actions-releases.md) owns the detailed requirements. `deploy-api` / `build-and-push` publishes images only; admission, activation, rollback and receipt enforcement remain work.                                                                      |

## Assumptions requiring current evidence

| #   | Assumption                                                                                              | If wrong                                                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | The measured host and service capacity fits the intended campaign workload.                             | Revisit deployment capacity and service isolation using fresh measurements; historical 458 MiB/150-user figures are not current evidence.       |
| A2  | The workstation and backup medium remain available between scheduled/pre-deployment pulls.              | D10's single-site data-loss risk persists; second-copy strategy and drill cadence remain open.                                                  |
| A3  | Browser/public configuration does not expose unintended direct database authority.                      | Review actual grants, RLS and provider identities; historical key secrecy and table counts are not current protection proof.                    |
| A4  | Actions, its protected jobs, credentials and target connectivity are available for an admitted release. | Stop production mutation. The September 19 D33 ruling supersedes the July local/manual fallback; do not bypass it while repairing availability. |
| A5  | Host and provider access remain scoped to their declared operational identities.                        | Review privilege separation and access independently; possessing SSH/provider access does not confer workstation production release authority.  |
