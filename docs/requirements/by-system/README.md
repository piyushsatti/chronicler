# Requirements by system

**Authority:** The requirement tables in these files are the living obligation source. Each row is a stable `R` id (native extracts) or `R` / `L` id where the system essay used that shape. Assumptions live in `## Assumptions` on the same page — they are not requirement rows.

The thin [systems map](/docs/systems.md) (and each page under `docs/systems/`) link here; they do not paste full tables. The curated [index](/docs/requirements/index.md) holds optional verdict one-liners and crosswalks each row to a by-system id or an `index-only` tag.
